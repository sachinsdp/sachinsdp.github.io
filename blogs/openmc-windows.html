Native Windows Compilation of OpenMC

Running the OpenMC Monte Carlo Neutron Transport Code Natively on Windows

Overview

OpenMC is a powerful Monte Carlo particle transport code widely used in reactor physics and radiation transport research. Traditionally, OpenMC is primarily developed and tested in Linux environments. This project demonstrates how OpenMC can be compiled and executed natively on Microsoft Windows systems while maintaining compatibility with the existing Python API and nuclear data libraries.

The goal of this work is to make OpenMC easier to use for students, researchers, and engineers who primarily work in Windows environments.

Key Features of the Windows Build

Native Windows Executable
Compatible with Python API
HDF5 Data Support
Portable Distribution
OpenMP Multithreading

The Windows build provides a native executable that can run directly on Windows 10 and Windows 11 systems without requiring Linux emulation or virtual machines.

Build Environment

The compilation was performed using the following setup:

Operating System: Windows 10/11 Build Environment: MSYS2 / MinGW64 Compiler: GCC (MinGW) Build System: CMake OpenMC Branch: master

The build system ensures compatibility with the OpenMC Python module so that simulations can be executed either directly from the command line or through Python scripts.

Compilation Steps

cmake .. -G "MinGW Makefiles" \ -DCMAKE_BUILD_TYPE=Release \ -DBUILD_SHARED_LIBS=OFF \ -DOPENMC_USE_MPI=OFF mingw32-make -j8

After compilation, the executable and required runtime libraries were packaged together to create a portable Windows distribution.

Portable Distribution

The compiled package is distributed as a portable folder containing:

openmc-windows/ bin/ openmc.exe required DLL libraries nuclear_data/ cross_sections.xml *.h5 nuclear data files examples/

All required runtime libraries are included so the executable can run on any compatible Windows system without additional installations.

Python Integration

The OpenMC Python API can still be installed using pip, allowing users to generate XML input files, run simulations, and analyze results exactly as done on Linux systems.

pip install openmc
